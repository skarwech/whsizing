## Open issues

- **Medium:** Findings 1, 2 and 3 above: the catalog date format, the missing cross-feature contracts, and a CI that cannot go green.
- **Low:** Findings 4 to 10 above.
- **Blockers outside F0's paths:**
  - `project/example_project.yaml` and a working `whsizing run-all` belong to F8 and F10. Until they exist, CI docker-smoke and `just docker-demo` cannot pass.
  - The CI coverage gate on `engine/*` and `finance/*` proves nothing until F6 and F7 code and tests exist.
  - The whole-tree lint and type gate in T0.1 will turn red if code from other features does not pass ruff or pyright.
- **Process note:** `.dockerignore` was created outside the literal list of paths F0 owns.

## Not applicable here and why

- **T0.5 in the Docker image:** Docker is not installed on this machine. The test exists and is skipped with the reason "Docker not installed".
- **T0.1 on real GitHub Actions:** GitHub CI is not available here. The workflow structure is tested, and the lint and type gates are run locally instead.
- **The docker-smoke job and `just docker-demo`:** they need `whsizing run-all` and `project/example_project.yaml` from F8 and F10.
- **The bench job and `just bench`:** no test is marked `bench` yet. Those tests belong to C5 and later features.
