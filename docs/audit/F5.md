## Open issues

- **Medium:** findings 1 to 4 above:
  - The assume flag overrides known violations.
  - The per-family schema is not enforced.
  - T5.3 reads a golden file that nothing produces.
  - Cube and S1 constants needed by F6 and F7 are missing.
- **Low:** findings 5 to 10 above.
- **Cross-feature contract hazards (from the build notes):**
  - `stock_growth_rate` is not a catalog id. description.md l.763 has F4 put it in `basis.overrides`, but ParamSet raises ConfigError on it. F4 must strip the key before building the ParamSet, or the team must agree on an `engine.*` id. This is unresolved.
  - `eligibility_shares` takes two extra required keyword arguments, `family` and `low_share` (finding 8). F6 callers must pass them.
  - The F7 S1 "charging" capex item has no parameter. F7 must decide how to handle it, for example by treating it as included in `per_robot_eur`.
  - Two values have no spec value at all and use analog placeholders with source TODO and confidence L: `engine.pack_station_oee` and `finance.kwh_per_station_year`.
  - The tests pin three counts: 68 params, 66 spec ranges and 71 constants. They must be updated when the domain expert adds parameters.
  - `docs/assumptions.md` must be regenerated with `uv run python -m whsizing.catalog.assumptions` after any catalog edit, comment edits included. Otherwise `test_docs_assumptions_md_is_regenerated` fails.
  - There is a spec inconsistency, kept verbatim. F6b (l.952) describes `area.peak_hour_share_inbound` 0.2 as a "5-hour window", while `receiving_window_hours` is 8 and `labor.inbound_window` is 06:00-14:00.
- **Schema change (additive):** `EligibilityResult.flags: list[Flag] = []` in `src/whsizing/schemas/result.py`.
- **Blocker outside F5's paths:** `src/whsizing/schemas/params.py:40` E501 (105 > 100). This is the `# ponytail:` comment in `Param._year_month`. It makes the whole-tree gate `tests/unit/test_f0_tooling.py::test_T0_1_lint_and_typecheck_gates_pass[ruff-check]` fail. The failure was confirmed on 2026-11-08. It is not an F5 failure.
